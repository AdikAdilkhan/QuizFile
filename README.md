# QuizFile
# File-Based Quiz Project (Консольный тест из файла)

Простой и удобный консольный проект на Python, который считывает вопросы и правильные ответы из текстового файла (`numbers.txt`), задает их пользователю, проверяет ответы и подсчитывает итоговый балл.

## 🚀 Основные возможности:
- Чтение вопросов и ответов из внешнего файла.
- Автоматическая очистка лишних пробелов с помощью метода `.strip()`.
- Подсчет правильных ответов и вывод итогового результата.
- Обработка исключений (`try-except`) на случай, если файл не найден.

## 📁 Структура файлов:
- `main.py` — основной файл с программным кодом.
- `numbers.txt` — файл с вопросами и ответами (в формате: `вопрос,ответ`).

## 💻 Как запустить?
1. Убедитесь, что у вас установлен **Python**.
2. Создайте в одной папке файл скрипта (например, `main.py`) и текстовый файл `numbers.txt`.
3. Запустите терминал в папке с проектом и выполните команду:
   ```bash
   python main.py
